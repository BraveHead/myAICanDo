关键约束

约束 当前实现
任务状态 只支持 pending、in_progress、completed。
写入语义 write_todos 每次完整替换当前 thread 的 todo 列表。
隔离边界 状态按 tenant_hash_id + user_hash_id + thread_id 隔离。
恢复来源 任务状态来自 todo store；消息卡片来自 assistant-ui repository。
